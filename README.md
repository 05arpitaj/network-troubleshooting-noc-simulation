# Network Troubleshooting & NOC Simulation

## 📌 Project Overview

A practical L1 Network Troubleshooting and NOC Simulation
created using Cisco Packet Tracer.

## 🛠️ Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI

## 🌐 Network Components

- 1 Cisco Router
- 2 Cisco Switches
- 6 PCs
- 1 Server

## 🔧 Skills Practiced

- IP Addressing
- Subnet Mask
- Default Gateway
- VLAN Basics
- Cisco IOS CLI
- Network Connectivity Testing
- Interface Troubleshooting
- Root Cause Analysis
- NOC Incident Handling

## 🎫 Troubleshooting Scenarios

1. Wrong IP Address
2. Wrong Default Gateway
3. Wrong Subnet Mask
4. Switch Interface Down
5. VLAN Connectivity Issue
6. Switch Interface Down on SW2

## 💻 Important Commands

- `ipconfig`
- `ping`
- `show ip interface brief`
- `show interfaces status`
- `show interfaces`
- `show vlan brief`
- `shutdown`
- `no shutdown`
